How it works

  • The menu users know stays almost the same. Only the 10 scattered master files are folded into Master Files.
  • Pinned: hover any page and click ★. Each user keeps their own favourites at the top.
  • Recent: the last 5 pages you opened, kept in your browser.
  • Search hides Pinned/Recent and filters the whole menu. Enter opens the first match.
  • Smallest change to how people already work. Least clean long-term, because Sales still has 10+ items.

Implied DB changes 1 new column

One new column on user_menus for pins, plus the Master Files grouping. Recent pages live in the browser (no DB). Preview only. You'll get the final SQL with the implementation plan.
