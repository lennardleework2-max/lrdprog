How it works

  • Pick a module in the top bar (Dashboard, Master Files, Purchasing, Sales, Inventory, Expenses, Admin).
  • The sidebar shows only that module, split into sections: the module's own pages first, then Uploads and Reports. Report groups fold open.
  • The module tab is chosen automatically from the page you're on. Opening Sales Transaction lights up “Sales”.
  • Search covers every module and shows where each page lives. Clicking a result switches module.
  • On mobile the top bar scrolls sideways and the sidebar becomes a drawer (☰).

Implied DB changes data only

No new columns or tables. Same idea as Option 1, but reports stay inside their module and the stand-alone “Reports” group is hidden. Level 1 rows become the top-bar modules; level 2 groups become sidebar sections. Preview only. You'll get the final SQL with the implementation plan.
