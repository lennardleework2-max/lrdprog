How it works

  • Pages are grouped by job: Master Files, Purchasing, Sales, Inventory, Expenses. Each group holds only that job's daily pages.
  • All reports in one place. Reports → pick the area (Sales, Purchasing, Inventory…) → pick the report.
  • Opening a group closes the others (accordion), so the sidebar never gets long.
  • Search box: type any part of a page name, or a group name like “costing”. Enter opens the first match. Esc clears.
  • A group shows only if the user can access at least one page inside it.

Implied DB changes data only

No new columns or tables. 3 new group rows, the rest are UPDATEs to mengrp / menidx. Renaming a group's mencap carries over to user_menus through the existing FK (ON UPDATE CASCADE). The menu will read layout from menus and permissions from user_menus, so per-user rows don't need re-syncing. Preview only. You'll get the final SQL with the implementation plan and run it yourself.
